# LLC Filing Process

## Stage 1 — Texas formation
Per potential LLC: complete official Texas Form 205, current Form 05-904 when seeking new-veteran-owned treatment, attach the VVL, submit through the authorized Texas SOS path, and preserve receipt/acceptance evidence.

Texas Form 205 requires entity name, registered agent/office, governing authority, purpose, initial mailing address, organizer, effectiveness, and organizer execution.

## Stage 2 — Post-formation governance
Execute the entity operating agreement and initial written consent only after formation/effectiveness.

## Stage 3 — EIN
Apply through the IRS. The responsible party for a non-government EIN application must be a natural person. Store taxpayer identifiers privately.

## Stage 4 — Government procurement
When the entity will compete:
- Federal: SAM.gov registration/UEI; entity-specific representations; then applicable SBA certifications such as VetCert.
- Texas: CMBL; VetHUB only if the entity independently satisfies current eligibility.
- Solicitation-specific: build a new response folder from the procurement checklist.

## Stage 5 — Receipts and renewals
Record direct receipts, status, expiration/renewal dates, and secure evidence pointers. Public repository state remains redacted.
