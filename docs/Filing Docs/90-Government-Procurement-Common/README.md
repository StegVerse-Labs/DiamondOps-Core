# Government Procurement — Common Filing Lane

This directory is the shared control surface for procurement registration and solicitation responses. Each LLC also has an entity-specific `04-Government-Procurement/` folder.

## Federal baseline
1. Accepted legal entity formation.
2. EIN.
3. SAM.gov full entity registration for direct federal awards; UEI is assigned during registration.
4. Entity-specific NAICS, representations/certifications, points of contact, banking/EFT data, and other SAM data.
5. Applicable SBA certification through current MySBA Certifications, including VetCert if eligible.
6. Opportunity-specific response package and receipt.

## Texas baseline
1. Accepted Texas formation.
2. Tax/vendor identity.
3. CMBL application where state-vendor participation is desired.
4. VetHUB only if current service-disabled-veteran, ownership/control, Texas-location, for-profit, and size criteria are independently met.
5. ESBD/Texas SmartBuy opportunity-specific response package.

## No cross-entity assumption
Each LLC must independently satisfy registration, certification, size, ownership/control, representations, and solicitation requirements. One affiliate's SAM, CMBL, VetCert, VetHUB, past performance, or award does not automatically transfer to another.
