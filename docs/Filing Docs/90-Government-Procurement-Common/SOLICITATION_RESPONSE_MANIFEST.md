# Solicitation Response Manifest

Create one folder per procurement using:
`<agency>-<solicitation-number>-<short-title>/`

Minimum contents:
- `00-SOLICITATION-SOURCE.md`
- `01-AMENDMENT-REGISTER.md`
- `02-COMPLIANCE-MATRIX.md`
- `03-TECHNICAL-RESPONSE.md`
- `04-PRICE-COST-RESPONSE.md`
- `05-REPRESENTATIONS-CERTIFICATIONS.md`
- `06-PAST-PERFORMANCE.md`
- `07-ATTACHMENT-MANIFEST.md`
- `08-SUBMISSION-CHECKLIST.md`
- `09-SUBMISSION-RECEIPT.md`

Do not populate a solicitation response from assumptions. The controlling solicitation and all amendments are source-of-truth.
