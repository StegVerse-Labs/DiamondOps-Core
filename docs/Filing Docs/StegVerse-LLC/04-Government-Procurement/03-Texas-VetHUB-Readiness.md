# Texas VetHUB Application Readiness — StegVerse LLC

VetHUB is a distinct Texas procurement certification. Do not claim eligibility merely from the VVL or veteran-owned formation benefit.

Current published eligibility includes service-disabled-veteran criteria, at least 51% qualifying ownership/control, day-to-day control, Texas principal place of business, for-profit status, and applicable size requirements.

## Eligibility gate
- [ ] owner meets current VetHUB service-disabled-veteran eligibility requirement
- [ ] qualifying owner holds at least 51%
- [ ] qualifying owner controls day-to-day operations
- [ ] principal place of business is in Texas
- [ ] entity is for-profit
- [ ] size eligibility confirmed
- [ ] supporting documents assembled

If any item is unverified, status = **NOT READY / DO NOT SUBMIT AS ELIGIBLE**.

## Evidence after application
- [ ] application receipt
- [ ] clarification requests resolved
- [ ] certification decision
- [ ] directory status verified
- [ ] expiration/renewal date recorded
